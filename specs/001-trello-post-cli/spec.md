# Feature Specification: Trello雑投稿CLIツール

**Feature Branch**: `001-trello-post-cli`  
**Created**: 2026-04-06  
**Status**: Draft  
**Input**: User description: "trelloにpostするRubyスクリプト(CLI)を作成。メッセージを受け取る。AI(ruby-openaiを使用)でタイトルと本文を生成。trello(trello-rubyを使用)にpostする。ボード、リストは環境変数で指定する。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ざっくりメッセージからTrelloカードを作成する (Priority: P1)

ユーザーはCLIからざっくりとしたメッセージ（例: 「ログイン画面のデザイン修正したい」）を入力する。システムはAIを使ってそのメッセージから適切なカードタイトルと詳細な本文を自動生成し、指定されたTrelloボードのリストに新しいカードとして投稿する。

**Why this priority**: これがこのツールの核心機能であり、この機能単体でユーザーに価値を提供できる。手軽にTrelloカードを作成できることで、タスク管理の手間を大幅に削減する。

**Independent Test**: CLIからメッセージを入力し、Trelloボード上に適切なタイトル・本文を持つカードが作成されることを確認する。

**Acceptance Scenarios**:

1. **Given** 環境変数が正しく設定されている状態, **When** ユーザーがCLIでメッセージを入力して実行する, **Then** AIがタイトルと本文を生成し、指定されたTrelloリストに新しいカードが作成される
2. **Given** 環境変数が正しく設定されている状態, **When** ユーザーが日本語のメッセージを入力する, **Then** 日本語で適切なタイトルと本文が生成される
3. **Given** カードが正常に作成された場合, **When** 処理が完了する, **Then** 作成されたカードのURLが表示される

---

### User Story 2 - エラー時にわかりやすいフィードバックを受ける (Priority: P2)

ユーザーが環境変数の設定漏れやAPIキーの誤りなどの問題がある状態でツールを実行した場合、何が問題なのかを明確に伝えるエラーメッセージが表示される。

**Why this priority**: ツールの信頼性と使いやすさに直結する。エラー時に何が起きたか分からないとユーザーが離脱する。

**Independent Test**: 環境変数を意図的に未設定にして実行し、わかりやすいエラーメッセージが表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** Trello関連の環境変数が未設定の状態, **When** ツールを実行する, **Then** どの環境変数が不足しているかを示すエラーメッセージが表示される
2. **Given** OpenAI APIキーが無効な状態, **When** ツールを実行する, **Then** AI APIへの接続に失敗した旨のエラーメッセージが表示される
3. **Given** メッセージが空の状態, **When** ツールを実行する, **Then** メッセージの入力を促すエラーメッセージが表示される

---

### Edge Cases

- メッセージが極端に短い場合（例: 1文字）でもAIが適切にタイトルと本文を生成できるか？
- メッセージが非常に長い場合（数千文字）にAI APIの制限に引っかからないか？
- ネットワーク接続が不安定な場合のタイムアウト処理はどうなるか？
- Trello APIのレート制限に達した場合の挙動はどうなるか？
- 指定されたボードやリストが存在しない場合のエラーハンドリングはどうなるか？

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ユーザーはCLIの引数としてメッセージを入力できなければならない
- **FR-002**: システムはAIを使って入力メッセージからカードのタイトル（簡潔な要約）を生成しなければならない
- **FR-003**: システムはAIを使って入力メッセージからカードの本文（詳細な説明）を生成しなければならない
- **FR-004**: システムは生成されたタイトルと本文を使って、指定されたTrelloリストに新しいカードを作成しなければならない
- **FR-005**: ボードIDとリストIDは環境変数で指定できなければならない
- **FR-006**: システムはカード作成成功時に、作成されたカードのURLを表示しなければならない
- **FR-007**: システムは必須の環境変数が未設定の場合、具体的なエラーメッセージを表示しなければならない
- **FR-008**: システムはメッセージが未入力の場合、使い方を示すエラーメッセージを表示しなければならない
- **FR-009**: システムはAI API・Trello APIの通信エラー時に、ユーザーにわかりやすいエラーメッセージを表示しなければならない

### Key Entities

- **メッセージ**: ユーザーがCLIから入力するざっくりとしたテキスト。カード生成の元となる情報
- **カード**: Trello上に作成されるタスクカード。タイトル（AIが生成した要約）と本文（AIが生成した詳細）を持つ
- **ボード/リスト**: カードの投稿先。環境変数で指定されるTrello上の場所

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーが1つのコマンドを実行するだけでTrelloカードが作成される（操作ステップが1回）
- **SC-002**: メッセージ入力からカード作成完了まで30秒以内に完了する
- **SC-003**: AIが生成するタイトルは入力メッセージの内容を的確に要約している
- **SC-004**: 必須環境変数が不足している場合、100%の確率でエラーメッセージが表示される

## Assumptions

- ユーザーはTrelloアカウントとAPIキーを既に持っている
- ユーザーはOpenAI APIキーを既に持っている
- ツールは主に日本語のメッセージで利用される
- 1回の実行で1枚のカードを作成する（バッチ処理は対象外）
- カードのラベル、期日、メンバー割り当てなどの追加属性は初期スコープ外
- ユーザーはRubyの実行環境を持っている
